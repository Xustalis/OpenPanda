已验证

  • 单机与可信内网三台真机（Orange Pi / MacBook / Windows）按设计使用：一句话进来分成「本地回答 / 派一个任务 / 跨机器的多阶段计划」，不可逆操作停在待审批队列等人批。
  • 真实跨网多跳已实测（Mac → 中继 → 云主机），3 MiB 项目树哈希一致。
  • main 上有 10 项必过检查；发版覆盖六个平台目标，每周跑一次安全扫描。
  • 守护进程空闲时常驻内存约 40MB，几乎不占 CPU。

未做

  • UPnP / NAT-PMP 自动端口映射。
  • punch / dir 帧的源签名收敛。
  • daemon → 面板的 mesh 指标 IPC：面板是独立侧车进程，读不到 daemon 内存里的计数器。

已知限制

  • 信任模型与沙箱在 docs/status.md 的「已知限制」里仍有未关闭的 P2 条目。
  • /rewind 快照仍在调用方 goroutine 上同步生成；上下文压缩后轮次编号会漂移。
  • 产物预览的跨节点拉取、文件查看器的符号链接窗口尚未收口。

接下来

v0.1.x 线上继续做桌面薄壳（托盘常驻、全局热键、原生通知、自更新）与稠密网格层。官网不承诺它的具体版本号。

参与

提 Issue、开 PR 都欢迎，合并前会跑完 10 项必过检查。从上面任意一条边界挑一个去复现，也是有效的贡献。

社区与贡献指南 → 提一个 Issue ↗ 读 docs/status.md ↗ 浏览源码 ↗

平台支持矩阵

六个正式发布目标加 Linux lite 变体；每个目标都有对应的归档与 SHA-256 条目。

OS ARCH 状态
macOS arm64 / amd64 正式发布，Apple Silicon 与 Intel Mac
Linux amd64 / arm64 正式发布，服务器、桌面与 ARM 开发板
Windows amd64 / arm64 正式发布，PowerShell 5.1 安装器
lite-linux amd64 / arm64 / armv7 无内嵌控制台与 TUI 的轻量变体，面向无头设备
源码构建 Go ≥ 1.26.10 无 CGO；make build 即可，控制台需先 make web

Windows 专属失败无法在 macOS 上伪装复现；遇到这类问题先按「测试夹具未与平台同步」排查。

验证到什么程度

把「跑通过」和「只在代码里落地」分开写，来源见 docs/status.md 的验证表。

检查 结论
make gate fmt-check、vet、build、adapter-test、test、race-focused 全绿；race-focused 覆盖 core / trust / bus / storage
make gate-all gate 之外加 web-gate 与两个 TUI PTY 契约，全绿
Web typecheck + 单测 + vite build exit 0（79 个前端测试）
三设备真机流水线 macOS ↔ Windows ↔ Linux SBC 实机跑通多跳委派、硬钉选、两跳流水线、执行中杀节点与断线重连
跨网项目树回传 Mac → 中继 → 云主机，3 MiB 项目树哈希一致
语音链路真机 未验：只验了缺驱动时正确报错并退出的降级路径

质量门禁

main 受分支保护：必须走 PR，必过检查全绿才允许合并，规则里没有绕过名单。

10 项必过检查

PR 阶段并行跑 lint、test、race、web、适配器契约、TUI PTY 与跨平台矩阵；推 main 之后还有一轮发版门禁。

竞态检测

内核是并发系统，go test -race 的发现按发布阻断项处理，不是警告；核心包尽量保持约 60% 以上覆盖率。

安全扫描

每周一跑一次 security.yml，另可手动触发；govulncheck 长期变红时先查工具链有没有新的补丁版本。

契约测试

适配器线协议由假 CLI 断言 argv、环境、进度与超时；TUI 的两条 PTY 契约钉住输入过滤与退出行为。

发版顺序是硬约束：先推 main，等该 SHA 的发版门禁全绿，再打 tag。给 feature 分支打 tag 不会触发发版管线。
