一键安装

安装器会自己解析平台对应的产物，多数人只需要这三条命令中的一条。

macOS / Linux默认最新稳定版
$curl -fsSL https://raw.githubusercontent.com/Xustalis/OpenPanda/main/scripts/install.sh | sh
Homebrew同一条 release 通道
$brew tap Xustalis/openpanda && brew install openpanda
Windows (PowerShell)PS 5.1 直接运行
PS>irm https://raw.githubusercontent.com/Xustalis/OpenPanda/main/scripts/install.ps1 | iex

校验你下载的东西

  • checksums.txt 逐项列出每个归档的 SHA-256；安装器在解包前核对。
  • checksums.txt.sig 是对该文件的 detached Ed25519 签名；本机 openssl 支持时安装器验签，自更新器一律强制验签。
  • macOS 自带 LibreSSL 3.3 不支持 Ed25519，此时安装器会明确告警而不是悄悄跳过；OPENPANDA_REQUIRE_SIG=1 把「无法验签」变成硬失败。
  • Windows PowerShell 5.1 无 Ed25519 原语，install.ps1 只做 SHA-256；Windows 网络栈的特殊情况写在 docs/install.md。
  • 降级会被拒绝：解包后比对新二进制的迁移上限与数据目录 schema，更旧版本一律拒绝；--force 才是有意的放行。

升级与卸载

01panda update checkpanda update apply

检查新版本 / 应用更新（验签通过后才换二进制）。

02curl -fsSL … | sh

重跑安装脚本即原地升级，配置、会话与数据保留。

03panda uninstall

移除二进制、PATH 标记块与自启单元；--purge 连数据一起删，--backup-only 先归档。

指定版本

macOS / Linux 用 --version 0.1.3，PowerShell 用 -Version 0.1.3 钉住某一版；预发布版必须显式指定，latest 永远只指最新稳定版。

系统要求

二进制是纯 Go 静态构建，运行时没有外部依赖；源码构建才需要下面三条工具链。

要求 说明
macOS / Linux / Windows amd64 与 arm64 六个正式发布目标，另有 Linux lite 变体
内存 约 40MB RSS（空闲守护进程） 不含你配置的模型与 agent CLI 自身占用
Python ≥ 3.10 适配器桥接脚本与语音侧车需要；lite 构建可免
Go / Node.js ≥ 1.26.11 / ≥ 18 仅源码构建：内核与内嵌 Web 控制台
网络 安装时需访问 GitHub releases 装完之后节点间只走你自己的网络

安装参数

一键脚本与 PowerShell 安装器支持的参数；latest 永远只指最新稳定版，预发布版必须显式指定。

PARAMETER 作用
--version 0.1.3 install.sh 钉住某一版，也可用环境变量 OPENPANDA_VERSION
-Version 0.1.3 install.ps1 的等价参数
--prefix <dir> 改安装根目录；默认 $XDG_DATA_HOME 或 ~/.local/share/openpanda
--lite 选无内嵌控制台与 TUI 的 Linux 变体，面向树莓派与纯命令行设备
-Yes / -NoService / -Force PowerShell 安装器：免确认、不注册登录计划任务、有意放行降级保护
--purge / --backup-only / --dry-run panda uninstall 的参数：连数据一起删、只归档、只看计划不动手

离线与手动安装

受限网络下可以先把产物和校验文件拷进内网，再手工解包；命名规则与安装器一致。

01panda-<version>-<os>-<arch>.tar.gz

macOS / Linux 归档；Windows 对应 panda-<version>-windows-<arch>.zip。

02checksums.txtchecksums.txt.sig

先核对 SHA-256，再验 detached Ed25519 签名；两者同信道送达时签名才是信任锚。

03tar -xzf …./openpanda/bin/panda version --json

解包后把 bin/ 加进 PATH；version --json 会同时给出二进制版本与数据库 schema。

受限网络下的完整做法（代理、镜像、OPENPANDA_UPDATE_BASE）写在 docs/install.md，按五种语言发布。

安装后验证

三条只读命令，用来确认装上去的那份就是刚下载的那份，且配置与端点都可用。

panda version --json版本与数据库 schema
$panda version --json
panda doctor配置、端点、适配器与网络诊断
$panda doctor
panda init初始化节点与能力卡
$panda init

如果 doctor 里出现「端点未配置」之类的拒绝项，先修配置再往下走；它打印的每一行都对应一个实际执行判定。
