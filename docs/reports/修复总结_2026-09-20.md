## 🔧 详细修复内容

### 1. Goroutine 资源泄漏修复

**问题描述**:
在 `lifetime.go` 的 `RunWithContext()` 函数中，goroutine 在 context done 时关闭了 `done` 通道，但 return func() 也可能尝试关闭同一个通道，导致 panic: close of closed channel。

**修复方案**:

```go
// 使用 sync.Once 确保只关闭一次
var doneOnce sync.Once
...
go func() {
    defer func() {
        doneOnce.Do(func() { close(done) })
    }()
    ...
}()
...
// 其他地方关闭时使用
doneOnce.Do(func() { close(done) })
```

**验证结果**:

- ✅ 单元测试 `TestLifetimeWithCancel` 通过
- ✅ Race detector 无警告
- ✅ 长时间运行无 panic

### 2. 错误处理改进（Fail-Closed 机制）

**问题描述**:
WebSocket 认证和审批接口在错误发生时返回 200 OK，攻击者可以轻易绕过认证。

**修复方案**:

```go
// WebSocket 认证 - 失败时返回 401
if !security.ValidateHMAC(req, secret) {
    w.WriteHeader(http.StatusUnauthorized)
    return
}

// 审批接口 - 失败时拒绝访问
if err != nil {
    entry.Error("approval", "reject unauthorized", "error", err)
    w.WriteHeader(http.StatusForbidden)
    json.NewEncoder(w).Encode(map[string]string{
        "status":  "error",
        "message": "unauthorized",
    })
    return
}
```

**验证结果**:

- ✅ `TestAPIAuthRequired` 通过
- ✅ `TestEmptyTokenFailsClosed` 通过
- ✅ `TestAuthRateLimited` 通过

### 3. SQLite WAL 性能优化

**问题描述**:
SQLite 使用默认模式，在高并发场景下可能出现写入瓶颈。

**修复方案**:

```go
// 启用 WAL 模式并优化参数
PRAGMA journal_mode = WAL;
PRAGMA synchronous = NORMAL;
PRAGMA wal_checkpoint(FULL);
PRAGMA busy_timeout = 5000;
```

**验证结果**:

- ✅ 数据库连接正常
- ✅ 写入性能提升
- ✅ 无死锁发生

### 6. 敏感信息过滤（新增功能）

**问题描述**:
项目打包时可能包含 API Key、Private Key 等敏感信息。

**修复方案**:
创建 `internal/core/sanitize.go`:

```go
var sensitivePatterns = []*regexp.Regexp{
    regexp.MustCompile(`(?i)\bapi_key\s*=\s*\S+`),
    regexp.MustCompile(`\bghp_[a-zA-Z0-9]{36}\b`),
    regexp.MustCompile(`\bsk-ant-[a-zA-Z0-9]{48}\b`),
    regexp.MustCompile(`-----BEGIN\s+(RSA|EC|DSA)\s+PRIVATE KEY-----`),
}

func FilterSensitiveData(input string) string {
    for _, pattern := range sensitivePatterns {
        input = pattern.ReplaceAllString(input, "[REDACTED]")
    }
    return input
}

func HasSensitiveData(input string) bool {
    for _, pattern := range sensitivePatterns {
        if pattern.MatchString(input) {
            return true
        }
    }
    return false
}
```

**集成点**:

- 项目打包流程自动调用
- 内存扫描检测敏感文件
- 日志输出自动脱敏

**验证结果**:

- ✅ `TestFilterSensitiveData` 通过（5/5 cases）
- ✅ `TestHasSensitiveData` 通过（5/5 cases）
- ✅ `TestScanProjectMemoryCredentials` 通过
